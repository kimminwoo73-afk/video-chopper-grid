# Video Chopper Grid 구현 계획

## 목표
`SPEC.md`에 적힌 기능을 모두 갖춘 단일 파일 웹앱 `index.html`을 만든다.
설치·빌드·서버 없이 파일을 브라우저로 열면 바로 동작해야 하고, GitHub Pages에 그대로 올라간다.

## 제약
- 순수 HTML + CSS + JavaScript. 프레임워크·번들러·외부 라이브러리 없음.
- 영상은 업로드하지 않고 브라우저 안에서만 처리 (`<video>` + `<canvas>`).
- 저장소 루트에 `index.html` 하나로 둔다 (Pages가 바로 서빙하도록).

## 작업 목록

### 1. 영상 로딩 (SPEC 1)
- 드롭존 클릭 / 드래그앤드롭으로 파일 받기
- `URL.createObjectURL`로 로드, 메타데이터에서 duration·해상도 취득
- 브라우저가 못 여는 코덱(avi/mkv 다수)은 오류 메시지로 안내

### 2. FPS 확보 (SPEC 전반의 전제)
- SPEC에 프레임 단위 조작이 많은데 `<video>`는 fps를 노출하지 않음
- `requestVideoFrameCallback`으로 프레임 간격을 재서 자동 추정, 흔한 값(23.976/24/25/29.97/30/50/60)으로 스냅
- 실패 시 30 기본값 + 사용자가 직접 입력할 수 있는 칸 제공

### 3. 타임라인 모드 (SPEC 2)
- `SCRUB`: 클릭·드래그로 탐색
- `CHOP`: 빈 곳 클릭 → 컷 추가 / 컷 라인 드래그 → 이동 / 컷 라인 클릭 → 삭제

### 4. 자르기 방식 (SPEC 3)
- `Every N Frames`: Interval 값으로 컷 자동 생성, `-`/`+`/숫자 입력
- `Manual`: 직접 지정. `Mark` 버튼으로 현재 위치에 컷 추가
- Interval 상태에서 컷을 손대면 그 목록을 그대로 Manual로 승계

### 5. 자동 컷 감지 (SPEC 4)
- 64×36으로 축소한 연속 프레임의 평균 픽셀 차이로 장면 전환 판정
- `SENS` 슬라이더로 임계값 조절 (높을수록 민감)
- 최대 600 샘플로 제한, 진행률 표시 + 취소 가능

### 6. LF / 마지막 프레임 (SPEC 5)
- `Add LF` 켜면 각 컷의 1프레임 직전을 앞에 끼워 넣음
- LF 칸은 그리드에서 파란 점선 테두리
- 영상 마지막 프레임은 설정과 무관하게 항상 마지막에 포함

### 7. 그리드 생성 (SPEC 6)
- `Scale` 1x / 1/2 / 1/4 / 1/8, `Grid cols` 지정
- 순서대로 seek → `drawImage`로 합성, 진행률 표시
- 캔버스 크기 상한 검사 (너무 크면 거부하고 안내)

### 8. 결과 확인·저장 (SPEC 7)
- 오버레이 미리보기: 휠 확대/축소(커서 기준), 드래그 이동
- `Fit` / `1:1` / `Copy`(클립보드) / `PNG`(다운로드) / `Close`

### 9. 단축키 (SPEC 8)
- `←`/`→` 1프레임, `Shift+←`/`→` 컷 이동
- `↑` 컷 추가, `↓` 가장 가까운 컷 삭제, `M` 컷 추가 (모두 CHOP 모드)
- 추가: `Space` 재생/일시정지, `Esc` 미리보기 닫기
