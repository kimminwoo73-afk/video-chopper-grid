

# Video Chopper Grid

동영상의 주요 프레임을 잘라 **한 장의 PNG 그리드 이미지**로 만드는 브라우저 도구입니다.

설치 없이 `index.html`을 열기만 하면 됩니다. 영상은 서버로 올라가지 않고 **브라우저 안에서만** 처리됩니다.

> 🚧 개발 중입니다. 자세한 기능 명세는 [SPEC.md](SPEC.md)를 참고하세요.

## 이런 데 씁니다

- 영상의 장면 전환을 한눈에 훑어보기
- 콘티·러프컷 검토용 시트 만들기
- 컷 직전 프레임과 컷 시작 프레임 비교하기

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 프레임 자동 분할 | N프레임마다 한 컷씩 자동 생성 |
| 수동 컷 지정 | 타임라인을 클릭해 원하는 위치에 컷 추가·이동·삭제 |
| 자동 컷 감지 | 장면 전환 지점을 자동으로 탐지 (민감도 조절 가능) |
| 구간 삭제 | 시작·끝 지점을 골라 필요 없는 부분을 빼기 (복원 가능) |
| LF 프레임 | 각 컷 직전 1프레임을 함께 추출해 비교 |
| 그리드 출력 | 배율·열 개수를 정해 한 장의 PNG로 합성 |
| 결과 저장 | PNG 파일로 내려받거나 클립보드로 복사 |

## 단축키

| 키 | 기능 |
| --- | --- |
| `←` / `→` | 1프레임 이전 / 다음 |
| `Shift + ←` / `→` | 이전 / 다음 컷 지점으로 이동 |
| `↑` | 현재 위치에 컷 추가 (CHOP 모드) |
| `↓` | 가장 가까운 컷 삭제 (CHOP 모드) |
| `M` | 현재 위치에 컷 추가 (CHOP 모드) |
| `I` / `O` | 삭제할 구간의 시작 / 끝 지점 |
| `Delete` | 선택한 구간 삭제 |
| `Shift + 드래그` | 타임라인에서 삭제할 구간 고르기 |

## 기술

순수 HTML + CSS + JavaScript. 빌드 도구도, 외부 라이브러리도, 서버도 없습니다.

- `<video>` — 영상 디코딩
- `<canvas>` — 프레임 추출 및 그리드 합성
